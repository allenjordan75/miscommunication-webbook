Textbook Editing Hub

Edit once. Publish once.

Use this page when you want to revise the live textbook without downloading anything. Each edit opens the file in GitHub. When you commit the change to main, the repository updates immediately and the published link updates through GitHub Pages.

Basic Workflow

1. Pick the page you want to change.

Open the chapter or resource in GitHub's editor. Small fixes can be made directly in the browser.

2. Edit the text carefully.

Keep the exact textbook terms intact: the common-sense approach and the (un)commonsense approach.

3. Commit to main.

Use a plain commit message such as "Revise Chapter 1 examples" or "Fix Chapter 0 terminology".

4. Check the published page.

GitHub Pages usually republishes within a minute or two. Refresh the published page after the commit finishes.
