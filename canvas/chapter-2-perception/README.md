# Chapter 2 Canvas Materials

This folder contains Canvas-ready materials for Chapter 2: Perception (Mis)Perception.

## Files

- `chapter-2-reading-canvas-page.html`
  Copy this HTML into a Canvas Page using the HTML editor.

- `chapter-2-perception-qti.zip`
  Import this ZIP into Canvas as a QTI quiz package.

- `chapter-2-quiz-answer-key.md`
  Instructor-facing answer key for quick review.

## Canvas Quiz Import

In Canvas, go to:

1. Settings
2. Import Course Content
3. Content Type: QTI .zip file
4. Choose `chapter-2-perception-qti.zip`
5. Import

Canvas should create a quiz titled:

Chapter 2: Perception (Mis)Perception Quiz
