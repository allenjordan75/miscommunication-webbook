## Chapter 0 Voice Moves To Use

Choose only the moves that fit:

- Open with a familiar assumption and complicate it.
- Translate a technical concept into student language.
- Use "The problem is not X. The problem is Y."
- Use "Not because... but because..."
- Ask a question that slows down certainty.
- Include a concrete everyday example.
- Use gentle humor only if it clarifies the point.

## Tone Notes

Student-facing, warm, clear, conceptually rigorous, conversational, concrete, occasionally funny, not generic textbook prose.

## Drafting Boundaries

Use `workflow/TEXTBOOK_GUIDE.md`. Treat Chapter 0 as the voice model and Chapter 2 as the structure model. Do not add unsupported claims. Do not rename key terms. Do not invent examples. Ask questions if the section goal, source support, or framework role is unclear.
